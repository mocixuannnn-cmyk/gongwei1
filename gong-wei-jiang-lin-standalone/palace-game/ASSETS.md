# 素材与外部依赖

- `palace-portraits.png`：早期四位宫装人物与皇子成长图集，保留以兼容现有代码。
- `consorts-expanded.png`：八位不同妃嫔的完整唐风立绘，4列2行。
- `royal-children-expanded.png`：皇子、公主各四阶段成长立绘，4列2行。
- `betty-kunfeng-tang.png`：李坤峰与韩佳璇的专属唐风Q版合绘。
- `portrait-prompt.txt`、`portrait-v8-prompts.txt`：保留的图片生成说明。

以上插画均为该游戏中已生成的素材。独立包不含用户上传的原始人物照片、账号信息或访问凭据。

运行时没有 CDN 脚本、外部字体、在线图片、API 调用或鉴权请求。地图、装饰和早期备用人物为源码内的 SVG/CSS；当前立绘来自本地 assets。

字体使用设备自带的衬线中文字体回退，不必联网下载字体。页面中的图片生成说明文件不会参与游戏运行。

历史风格及月例采用游戏内注明的参考与折算规则；本项目为架空故事，不作精确历史制度复原。
