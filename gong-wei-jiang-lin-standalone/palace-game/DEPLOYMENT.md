# 部署速查

## 无需构建的部署

将 `dist/` 内的全部文件和 `assets/` 目录上传到静态托管服务。入口为 `index.html`。

- 类型：纯静态网站。
- 发布目录：`dist`。
- 运行时后端：无。
- 环境变量：无。
- ChatGPT 登录、API 密钥：均不需要。
- 数据库：无；浏览器本地存档。
- 路径：使用相对路径，支持根域名与子路径。

## 需要构建的部署

```bash
npm run check
npm run build
```

构建后发布 `dist`。不需要安装任何 npm 包。

## 本地检查

```bash
npm start
```

访问 http://127.0.0.1:8080/。

部署完成后，请检查首页、立绘、商店和存档导入；从旧预览迁移时先导出旧站存档，再到新站导入。

## 图片不显示

确保 `assets/` 与 CSS、HTML、JavaScript 一起上传，文件名大小写保持原样。不要把 assets 单独放到站点外，也不要只上传源码而漏掉素材。

## 出现 ChatGPT 登录页

本独立项目内没有 ChatGPT 登录逻辑。若仍访问原来的预览地址，就仍是在打开原站点；应打开静态托管服务生成的新网址。
