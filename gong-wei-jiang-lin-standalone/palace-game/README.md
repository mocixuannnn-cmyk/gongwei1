# 宫闱将临 · 独立静态版

这是当前预览第8版的完整独立项目。游戏、剧情、地图、人物立绘、子嗣、存档、密令和专属彩蛋均保留。

**运行不需要 ChatGPT 登录、OpenAI API、API 密钥、数据库或后端服务。** 所有脚本、样式和立绘都在项目中；外部字体请求已移除，使用设备自带的宋体/衬线字体。首次把网页及图片从自己的托管服务加载完成后，游戏逻辑与图片不需要调用任何第三方服务。

## 最快部署：直接使用 dist

压缩包已经包含构建完成的 `dist/`，不必运行安装或构建命令。

1. 解压 ZIP。
2. 打开项目中的 `dist` 文件夹。
3. 将 **dist 内的全部内容** 上传到任意静态网站托管服务或服务器网站目录。
4. 部署入口是网站根目录的 `index.html`。

务必同时上传 `game.js`、`style.css`、`extra.css` 和 `assets/` 内的全部文件。不要只上传 HTML，也不要把项目 ZIP 当成网页文件。

如果托管服务要求“发布目录”或“输出目录”，填写 `dist`。若服务要求上传一个文件夹，选择 `dist`；若要求选择多个文件，则选择 `dist` 内的所有文件和 `assets` 文件夹。最终访问路径应能直接找到 `index.html`，而不是多套一层 `dist/dist`。

## 本地运行（任选一种）

### 方法一：Node.js，零第三方依赖

先安装支持 Node.js 18 或以上版本的运行环境。在项目文件夹内打开终端：

```bash
npm run dev
```

浏览器打开 `http://127.0.0.1:8080/`。

**不需要运行 npm install。** 项目的运行依赖和开发依赖均为空，启动脚本只使用 Node.js 内置模块。

预览打包好的部署文件：

```bash
npm start
```

更换端口：

```bash
npm start -- --port 9090
```

需要同一局域网其他设备访问时，显式指定监听地址：

```bash
npm start -- --host 0.0.0.0 --port 8080
```

通过电脑的局域网 IP 访问即可；这仍是本地静态服务。

### 方法二：Python

如果电脑已经安装 Python，可直接进入 dist 目录：

```bash
cd dist
python -m http.server 8080
```

macOS/Linux 如需使用 `python3`：

```bash
python3 -m http.server 8080
```

浏览器打开 `http://127.0.0.1:8080/`。

直接双击 HTML 在部分浏览器也能显示页面，但浏览器对 `file://` 存档的处理不一致；建议使用以上任一静态服务方式。

## 修改源码与重新构建

直接编辑项目根目录的 HTML、CSS、JavaScript 和 assets，不要只改 dist 中的副本。

```bash
npm run check
npm run build
npm start
```

`build` 会重新生成 dist；请以根目录源码为准，避免改动被覆盖。无需打包框架、构建插件或联网安装依赖。

## 常见静态托管方式

- **拖拽/直接上传型静态托管**：使用现成的 dist 内容，不需要构建。
- **从 Git 仓库构建的托管**：提交本项目，构建命令 `npm run build`，发布目录 `dist`。项目带有 `netlify.toml` 和 `vercel.json` 作为可选配置。
- **GitHub Pages**：把 dist 的内容发布到 Pages 对应的网站目录/分支，包含 `.nojekyll`。所有网页资源都使用相对路径，可放在仓库子路径下。
- **Nginx、Apache、对象存储静态网站等**：将 dist 内的文件放进站点根目录，默认首页设为 index.html。它是多资源单页静态游戏，不需要服务端路由重写。

这些方式部署出的游戏本身没有账号系统，不会跳转至 ChatGPT 登录。托管平台自己的管理账号与玩家访问游戏是两回事。

## 存档迁移

游戏使用当前浏览器、当前站点的 localStorage 自动/手动存档，保留存档文件导入导出。

旧预览地址与新部署地址属于不同站点，浏览器不会自动共享存档：

1. 在旧游戏打开“存档 / 读档”。
2. 选择“导出存档”，保存 JSON 文件。
3. 在新的独立网站打开“存档 / 读档”。
4. 选择“导入存档”，导入该 JSON 文件。

更换设备、浏览器、域名或本地端口时，也请采用导出/导入。清除站点数据会清除该浏览器内的存档。项目不上传存档，也不包含任何玩家的实际存档。
